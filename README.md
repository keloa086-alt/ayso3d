# Ayso 3D — تحويل النص والصورة إلى مجسّم ثلاثي الأبعاد

مولّد مجسّمات يعمل **بالكامل داخل المتصفح**: بلا سيرفر، بلا حساب، بلا مفاتيح API، بصفر تكلفة.
ملف واحد `index.html` فيه المحرّك والمصيّر والواجهة.

## الموديل المدرَّب (تعلّم من الصفر داخل المتصفح)

بدل النماذج الجاهزة، الصفحة فيها شبكة عصبية **تبدأ بأوزان صفرية** وتتدرّب أمامك:

- الترميز: النص ← ٣٨٤ ميزة مُهشَّرة (كلمات + ثلاثيات أحرف، تطبيع L2)
- الشبكة: `384 × 21,952` وزن + `21,952` انحياز = **٨٬٤٥١٬٥٢٠ معامل**
- المخرج: شبكة إشغال `28×28×28` (احتمال وجود المادة في كل خلية)
- التدريب: Adam + خسارة BCE‏+Dice، ٥٠ حقبة، ١٢٠ نصاً (١٥ صنفاً × ٨ صيغ)، **تلقائياً عند فتح الصفحة** في **~٩٠ ثانية** خارج المتصفح (أو ~٣٠ ثانية في المتصفح عند إعادة التدريب)
- تسريع: عيّنات سالبة عشوائية (٤٥٪ من الخلايا) + تخطيط أوزان صفّي `W[d*K+k]` + أوزان تعويضية للتوازن
- النتيجة: IoU على بيانات التدريب **٩٩٫١٪**، وعلى نصوص **ما شافها** **~٦٨٪**
- **الأوزان مضمَّنة مع الموقع** (`model.bin`, int4 كُمّي: ‎2.6MB → ~0.9MB مضغوطة): تُحمَّل وتُفكّ في **~25 مللي ثانية**، فالصفحة تفتح والموديل جاهز بلا انتظار وبلا شريط تقدّم
- التحقق: التكميم إلى 4 بت لم يخفّض الجودة — IoU ١٠٠٪ و ٧٠٫٨٪ على النصوص غير المرئية بعد التكميم
- الأوزان تُحفظ أيضاً في **IndexedDB** بعد أي إعادة تدريب يدوية
- تنقية المخرج: أكبر مكوّن متصل + سد الثقوب الصغيرة + إغلاق الفجوات الداخلية
- الاستنتاج: النص ← الشبكة ← شبكة الإشغال ← مجسّم (وجوه خارجية فقط) ← OBJ/GLB/STL

كل الحساب على جهاز الزائر: لا سيرفر، لا GPU، لا مفاتيح.

## الميزات

- **أي وصف ← مجسّم (محرّك اللغة)**: معجم ٤٥+ كلمة، تحليل تلقائي للألوان (١٦ لوناً)، الأعداد (٢–٦)، الأبعاد (طويل/عريض/مسطّح/نحيف)، تركيب حتى ٤ أجسام في مشهد واحد، ومولّد إجرائي ثابت (deterministic) لأي كلمة ما نعرفها — فما يوجد وصف يرجع فاضي.
- **نص ← مجسّم**: ٣٨ وصفة + ١٥ صنفاً (كرسي، طاولة، بيت، شجرة، سيارة، كأس، صاروخ، سيف، مصباح، برج، مكعب) + تركيبات من مجسّمين.
- **صورة ← مجسّم**: استخراج الشكل من الصورة وتحويله إلى جسم مجسّم.
- **زوايا متعددة**: ٢–٤ صور لنفس الجسم.
- **وضع فوكسل**: تحويل المجسّم إلى شبكة فوكسل مصمتة بحدود خارجية فقط.
- **أساليب**: طبيعي، خشب، معدن، باستيل، رمادي.
- **تصدير**: OBJ · GLB · STL · PNG — يفتح في Blender و Unity و Godot و Three.js وأدوات الطباعة ثلاثية الأبعاد.
- **مصيّر خاص**: z-buffer مكتوب من الصفر على Canvas 2D (بلا WebGL ولا مكتبات)، مع وضع أسلاك وإخفاء الخطوط المخفية.

## التشغيل

افتح `index.html` في أي متصفح حديث. لا يحتاج بناءً ولا تثبيت.

أو استخدم نسخة GitHub Pages بعد النشر.

## النشر

**Vercel:** استورد المستودع ← Framework Preset: `Other` ← Build Command: فاضي ← Output Directory: `.` ← Deploy.
**GitHub Pages:** Settings → Pages → Branch `main` / root.
**Cloudflare Pages:** اربط المستودع ← Framework: None ← Build: فاضي ← Output: `/`.
